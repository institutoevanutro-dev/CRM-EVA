titulo: Next.js e duas bibliotecas internas sobem para versões com correção de segurança
---
O Next.js sobe de 16.3.4 para 16.3.8, que fecha uma falha grave de requisição forjada pelo servidor no otimizador de imagens e falhas de cache e de vazamento de conteúdo. As bibliotecas de imagem (`sharp`, para 0.35.5) e de mapa de código (`source-map-js`, para 1.2.2) sobem para as versões corrigidas. Nada muda no uso: a atualização é interna e não pede ação de quem opera o servidor.
