Só o administrador conclui o assistente, vê o QR de pareamento e cria modelos
no canal intermediado. Novos códigos de recuperação pedem o código do
aplicativo. Arquivo de contato que não é imagem, áudio, vídeo ou PDF é baixado,
não aberto. A API de envio recusa `media_url`: use `media_storage_path`.
