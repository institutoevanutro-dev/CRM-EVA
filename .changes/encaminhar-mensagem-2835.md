titulo: No chat, uma mensagem pode ser encaminhada para outra conversa
---

A bolha ganha o botão Encaminhar, ao lado do Responder: escolha a conversa de destino entre as conversas já carregadas na lista, e a mensagem vai para lá pelo mesmo caminho do envio normal, com texto e mídia (a mídia é copiada para a conversa de destino). Quando a mídia ainda não chegou ao CRM, a recusa pede para tentar de novo em instantes; a mídia que nunca poderá ser encaminhada, como a proposta em PDF ou a imagem que a retenção já apagou, recebe uma recusa própria. Dois toques seguidos encaminham uma vez só, e quando o envio para o destino falha o aviso diz isso, com o motivo. Mensagem apagada não se encaminha.

Portado do projeto original (DeskcommCRM, PR #2841 de @webtecnica).
